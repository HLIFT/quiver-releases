# Quiver

Launcher de jeux pour Windows 10 et 11 : tes bibliothèques Steam et Epic Games dans une seule application, avec lancement, installation et mises à jour des jeux (Epic sans le launcher Epic, Steam via son client).

Ce dépôt ne contient que les versions publiées de Quiver.

## Installer

1. Télécharge `Quiver.exe` dans la [dernière version](https://github.com/HLIFT/quiver-releases/releases/latest).
2. Lance-le et choisis « Installer » : Quiver se copie dans ton dossier utilisateur (sans droits administrateur), s'ajoute au menu Démarrer et à la liste des applications de Windows. Le fichier téléchargé peut ensuite être supprimé.
3. Le programme n'est pas signé : Windows SmartScreen peut afficher « Windows a protégé votre ordinateur ». Clique sur « Informations complémentaires », puis « Exécuter quand même ».

## Mises à jour

Quiver vérifie les nouvelles versions au démarrage puis une fois par jour, et s'installe en un clic (« Mettre à jour et redémarrer »). Chaque version est accompagnée de `Quiver.exe.sha256` : Quiver vérifie le fichier téléchargé avant de l'installer.

## Désinstaller

Paramètres Windows › Applications › Applications installées › Quiver › Désinstaller. Tes jeux ne sont pas touchés ; Quiver propose de garder ou de supprimer ses propres données.
